# Drums

Drums is building infrastructure for computer-use RL, so AI labs can run more training attempts on less hardware.

![One running OS](docs/img/landing-one-running-os.png)

## Experiment 1: sessions per Studio

How many isolated computer-use environments can one Mac run without virtual machines? This repo holds the tools to measure that number, the cost per valid rollout, and any cross-contamination between sessions.

Status: nothing measured yet.
